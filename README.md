# Go Scraper

Конкурентный веб-скрапер на Go. Собирает ссылки со страницы, использует пул воркеров и сохраняет результат в JSON.
Только стандартная библиотека, без внешних зависимостей.

## Что умеет

- Скачивает HTML-страницу и вытаскивает из неё ссылки с текстом.
- **Пул воркеров** — обрабатывает страницы параллельно (по умолчанию 4 воркера).
- **Таймауты** — не зависает на медленных сайтах.
- **Ограничение размера** — не скачивает страницы больше 5 МБ.
- **Дедупликация** — одинаковые URL не попадают в результат дважды.
- Сохраняет результат в `articles.json`.

## Запуск

```bash
go run ./cmd/scraper -url=https://example.com -workers=4
